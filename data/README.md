# Data

## Tennessee Eastman Process

Both datasets were generated and published by Oliveira e Souza et al. (2024):
<https://github.com/anasouzac/new_tep_datasets>

| File | Simulator | Used as |
|---|---|---|
| `matlab_data_1year.csv` | revised TEP simulator (Bathelt et al., 2015) | revised dataset (primary) |
| `python_data_1year.csv` | original TEP simulator (Downs & Vogel, 1993) | original dataset (replication) |

The files are stored with Git LFS; download them with `git lfs pull` or the "Download raw file" button.
Convert each one into a dataset root:

```bash
cd tep
python prepare_data.py /path/to/matlab_data_1year.csv ../runs/revised
python prepare_data.py /path/to/python_data_1year.csv ../runs/original
```

Each root then holds `data/tep_clean.npz` (52 channels XMEAS(1-41), XMV(1-11); label STATUS) and an empty `out/`.
No samples, classes or channels are removed.

## Reactor

The reactor data are generated by `reactor/simulate.py` (fixed random seed) into `data/reactor.npz` and
`data/meta.json`.
